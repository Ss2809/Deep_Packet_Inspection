# Deep Packet Inspection

This project is a C++ based Deep Packet Inspection (DPI) system for analyzing PCAP files and identifying network traffic.

## Features

- PCAP file reading
- Ethernet packet parsing
- IPv4 parsing
- TCP/UDP parsing
- Connection tracking
- Rule-based traffic detection
- Deep Packet Inspection
